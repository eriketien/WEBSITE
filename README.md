# Erik ETIEN – Rapport d'activités

Site web statique (une page) généré à partir du rapport d'activités.

## Contenu
- `index.html` : la page (styles et scripts intégrés)
- `assets/` : les graphiques
- `.nojekyll` : indique à GitHub Pages de servir les fichiers tels quels

## Mise en ligne avec GitHub Pages
1. Créer un dépôt sur GitHub (par ex. `rapport-activites`).
2. Y déposer le contenu de ce dossier (bouton **Add file → Upload files**, ou `git push`).
3. Dans le dépôt : **Settings → Pages → Build and deployment**, choisir
   *Source : Deploy from a branch*, branche `main`, dossier `/ (root)`, puis **Save**.
4. Après une minute environ, le site est en ligne à l'adresse
   `https://<votre-identifiant>.github.io/rapport-activites/`.
